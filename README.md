## 💡 What It Taught Me

Implementing these structures by hand — rather than just using `std::vector` or `std::map` — gave me an intuition for what's happening behind the scenes in any language. Writing the Knight's Tour solver taught me about backtracking and game tree search in a concrete, visual way. The hashing lab made hash collision strategies real: you can read about chaining vs. open addressing in a textbook, but implementing them yourself is when the trade-offs become obvious. I also got comfortable with CMake builds and writing meaningful unit tests with Google Test alongside my implementations.
